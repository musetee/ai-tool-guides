# AI tool guides

**Short, practical guides to AI agent plugins and skills worth using: what each one does, where to start, and what to watch out for. For people who use AI coding agents (Claude Code, Codex …) and want to know quickly whether a plugin is worth installing.**

Each guide is one page with tables; the list below gives the one-line summary and links to it.

## 📚 Guides

| Plugin / skill set | Works with | What it does | Guide |
| :--- | :--- | :--- | :--- |
| **mattpocock-skills** (Matt Pocock) | Claude Code, Codex, GitHub Copilot, Gemini CLI | 27 small engineering skills: question a plan until it is clear (`grill-me`), spec → tickets → implement, test-driven development, hard-bug diagnosis, two-axis code review, architecture and domain modelling, handoff documents | [English](guides/mattpocock-skills.md) · [中文](guides/mattpocock-skills_cn.md) |

## 🙋 Notes

- Each guide says which version it describes and when; plugins change, so check the version you installed.
- The summaries describe what the plugin's own files say; where a guide has not been tried in practice, it says so.
- Plugin names and descriptions belong to their authors; each guide links to the original repository and its licence.
